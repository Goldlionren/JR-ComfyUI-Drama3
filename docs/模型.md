# 模型下载与存放

下文用 `<项目>` 表示本插件的仓库根目录，用 `<Comfy>` 表示含 `main.py` 的 ComfyUI 目录。两种系统使用同一套模型文件。以下 `python` 均指[安装指南](安装部署.md)中为当前路线选定的解释器。所有 GB 均按十进制计算。

## 只做推理要下载什么

按使用的入口选一行。表里的 FP8「教师」也可直接合成语音，使用已发布的 NVFP4 GGUF 只需准备对应的实时引擎。转写、翻译和视频模型按实际功能另选。需要微调或训练 LoRA 时，训练基座与数据格式由外部训练工具决定。[训练准备与权重兼容性](安装部署.md#需要训练)

| 入口 | 下载内容 | 完整权重大小 | 默认位置 |
|---|---|---:|---|
| 教师节点与 8193 | 官方 Drama 3 FP8 快照，十五个 safetensors 分片及 codec 等配套文件 | 41.50 GB | `<项目>/.runtime/teacher/` |
| 8195 五语 | 五语 GGUF 及其同名 SHA-256 校验文件，使用项目适配的 CUDA 引擎 | 14.11 GB | `<项目>/.runtime/Drama3-Tier2-5Lang.gguf`，旁边放 `Drama3-Tier2-5Lang.gguf.sha256` |
| 8195 NVFP4 | 保留 256 个专家的 GGUF，另取引擎源码与补丁 | 22.24 GB | `<项目>/.runtime/Drama3-V2-78e5ab7-NVFP4-256E.gguf` |
| 8195 Q4_K | Q4_K GGUF，另取当前系统的 Vulkan 引擎 | 20.79 GB | `<项目>/.runtime/Drama-35B-A3B-v3-Q4_K.gguf` |

## 官方教师

在项目根目录运行。第一行取得固定提交的 Fish Speech 源码并校验、解包 DAC wheel；第二行通过 Hugging Face 下载模型清单中的文件并逐项验证字节数和指纹。

```text
python jr_runtime/setup_runtime.py
python tools/fetch_teacher.py
```

固定模型为 `fishaudio/drama-3@78e5ab79e49aa9a25abe8799eff2c4d73a1c3216`，推理源码为 `fishaudio/fish-speech@0f8a12e8a651062fdee9c33a894bdccd3a8513f1`。手工下载时保留同一快照的相对文件名，确保 `config.json`、`model.safetensors.index.json`、`model-00001-of-00015.safetensors` 至 `model-00015-of-00015.safetensors`、`codec.pth`、分词器和模板都在模型根目录。完整文件表包含大小与官方 SHA-256 或 Git blob 指纹。请给旧八分片单独保留目录。[官方快照](https://huggingface.co/fishaudio/drama-3/tree/78e5ab79e49aa9a25abe8799eff2c4d73a1c3216) · [完整清单](../resources/teacher.json)

**已有统一的模型盘**时，可执行 `python tools/fetch_teacher.py --dest "<Comfy>/models/drama3"`（替换为实际路径）。节点依次查找手填目录、`JR_DRAMA3_MODEL_DIR`、`<项目>/.runtime/teacher`、ComfyUI 注册的 `drama3` 路径、`<Comfy>/models/drama3`、`<Comfy>/models/tts/drama-3`。前两项是显式选择，自定义路径填本机目录。下载器的 `--dest` 决定写到哪里，运行时变量决定从哪里读。[查找与校验代码](../jr_teacher.py)

```powershell
$env:JR_DRAMA3_MODEL_DIR = 'D:\Models\Drama3\teacher'
& $py tools/fetch_teacher.py --dest $env:JR_DRAMA3_MODEL_DIR
```

```bash
export JR_DRAMA3_MODEL_DIR="$HOME/models/drama3/teacher"
"$PY" tools/fetch_teacher.py --dest "$JR_DRAMA3_MODEL_DIR"
```

`JR_DRAMA3_RUNTIME` 控制教师推理源码、`vendor/` 和 `wheels/` 所在目录，默认 `<项目>/.runtime`。实时 GGUF、分析模型和教师下载器的默认目录各自独立。需要 FLA 时执行 `python jr_runtime/setup_runtime.py --fla`；在教师节点开启「FLA 加速」后重新排队。

**在 WSL2 复用 Windows 模型盘**时，例如 Windows 的 `F:\AI\JR-ComfyUI-Drama3\.runtime\teacher`，给 Ubuntu 进程设置 `JR_DRAMA3_MODEL_DIR=/mnt/f/AI/JR-ComfyUI-Drama3/.runtime/teacher`。首次读取和验证约 41.5 GB，可能需要数分钟。常用 Ubuntu 时也可以把完整模型放到 Linux 本地磁盘，再将变量改为该目录。

## 实时语音模型

五语、NVFP4 和 Q4_K 分别使用 `JR_DRAMA3_5LANG_MODEL`、`JR_DRAMA3_NVFP4_MODEL`、`JR_DRAMA3_Q4_MODEL`。指定本机 GGUF 的完整绝对路径，准备脚本和启动器就会复用它。五语另需保留旁边的 `.gguf.sha256`，五语和 NVFP4 共用同一套 audio.cpp 可执行程序。[三个后端的模型与引擎位置](ComfyUI纯推理.md#model-paths) · [从源准备五语模型](五语推理.md#转换与复测)

在 Windows 用 `.\tools\prepare_realtime.ps1 -Backend nvfp4`，Ubuntu 用 `bash tools/prepare_realtime.sh nvfp4`。选择 Q4_K 时参数改成 `q4`。脚本从固定修订取 GGUF，核对 SHA-256，再为当前系统准备引擎。已具备完整权重时，可先复制到表中确切位置再运行脚本，脚本会校验已有文件。下载中断可重新运行；如暂存文件校验失败，移走报错的 `.partial` 后重新下载。

| 后端 | 固定版本与验证 | 准备好的可执行程序（相对于 `<项目>/.runtime`） |
|---|---|---|
| NVFP4 | 模型库 `06cfd87`，GGUF SHA-256 `5577beb99be7bc0f4c8324daea90e2f3c8765d17842db41016560fb4820312b1`。使用 `audio.cpp@066ea98` 与模型作者补丁。 [模型与补丁](https://huggingface.co/WonderChord/Drama3-V2-NVFP4-256E-GGUF/tree/06cfd87d3aa87cdd37e816fac6da485b8f6cbdb4) | Windows `audio.cpp/build/windows-cuda-release/bin/audiocpp_server.exe`；Ubuntu `audio.cpp/build/linux-cuda-release/bin/audiocpp_server` |
| Q4_K | 模型库 `9a01354`，GGUF SHA-256 `2a57b14c9b208a2ff833ab7305b920ca8f154ad807004a52d96a86a90a55523e`。引擎使用 v0.11.2 对应平台的 x64 Vulkan 包。 [模型快照](https://huggingface.co/sakasegawa/drama-3-GGUF/tree/9a01354d04ab6eb521bc9cdfc56ab6824c474af2) · [引擎发布包](https://github.com/nyosegawa/speech.cpp/releases/tag/v0.11.2) | Windows `speechcpp/speech.exe`；Ubuntu `speechcpp/speech`，保留同目录配套库 |

启动器也会核对两份合成参考 WAV 的指纹。请保留 `example_workflows/jr-benchmark-references/zh.wav` 和 `en.wav`。客户端使用内置 `zh`、`en` 时直接传名称。两种后端都接受自定义参考录音、逐字稿和已注册的音色 ID。

## 按功能安装可选模型

仅做单句合成时可以跳过本节。转写、翻译、说话人和视频节点按需要准备；已有正确逐字稿时可直接克隆。

```text
python -m pip install openai-whisper transformers sentencepiece sacremoses
python jr_analysis_prepare.py whisper en-zh zh-en
```

参数可单选，例如 `python jr_analysis_prepare.py whisper`。使用 `--output-dir` 改下载目录后，给节点传实际文件或目录，或设置下表变量。Windows 用 `$env:变量名 = '路径'`，Ubuntu 用 `export 变量名="/路径"`，然后从这个环境启动 ComfyUI。

## 离线安装与迁移

1. 联网机器准备对应路线的完整模型并完成校验。教师还要保留固定提交的 `fish-speech/`（含 `.git`）、`wheels/`、`vendor/`。额外 Python 依赖在目标系统的环境中安装，可预先准备匹配目标 OS、Python 与 CUDA 版本的 wheel。
2. 复制教师运行目录和模型后，执行 `python jr_runtime/setup_runtime.py --offline`；使用 FLA 时再执行 `python jr_runtime/setup_runtime.py --fla --offline`。在目标机加载教师会再次验证权重。
3. 实时服务可复制 GGUF 和内置参考 WAV。先在相同目标平台准备完整引擎及其依赖，或在目标机编译；启动时直接执行 `realtime_service.py start`。不要把另一台机器的 PID 记录或监听 IP 带过去。
4. 模型与个人声音分别存储。需要保留音色 ID 和历史录音时按[声音资产与备份](声音资产.md)迁移。
