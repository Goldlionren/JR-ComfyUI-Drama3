# Windows 和 Ubuntu 节点兼容性审查

审查覆盖插件注册的 49 个 ComfyUI V3 节点。打开旧图后，在「语音模型（FP8 / GGUF）」的 `model` 里选择 `drama-3-5lang`、`drama-3-nvfp4` 或 `drama-3-q4`，原来的 `teacher` 连线可以继续使用。该下拉框默认保留 FP8。「实时语音」有自己的模型选择器。使用 GGUF 前先启动同机 8195 服务。安装位置和启停命令见[纯推理部署](ComfyUI纯推理.md)。

## 合成、模型及缓存

节点 ID 省略共同前缀 `JRDrama3`。表中“五语”指五语言 GGUF。

| 节点 | 五语 | NVFP4 | Q4_K | 使用条件 |
|---|---|---|---|---|
| `Teacher` 语音模型 | ✓ | ✓ | ✓ | 通过 8195 核对所选模型与权重指纹。目录和 FLA 开关仅供 FP8 使用 |
| `Sampling` 采样 | ✓ | ✓ | ✓ | 温度、top-p、top-k、帧上限传给实际引擎。Q4 的时长上限由帧数换算 |
| `Generate` 语音生成 | 分句、设计、续写、返修 | 同五语 | 分句、设计 | 多角色用台本的 `text`、`cast` 和 `line`。原生整场 `scene_json` / `scene` 使用 FP8 |
| `Infill` 上下文局部补录 | FP8 专用 | FP8 专用 | FP8 专用 | 需要同时编码选区两侧上下文和完整新稿，保留原有补录语义 |
| `Candidates` 候选 | ✓ | ✓ | ✓ | 每份候选绑定模型 ID、权重指纹、台词、采样和参考音 |
| `SelectTake` 选择候选 | ✓ | ✓ | ✓ | 从磁盘用编号或 take ID 取回已完成的音频 |
| `CheckedTake` 回听重录 | ✓ | ✓ | ✓ | 所选 GGUF 生成，独立的 Whisper small 回读，按限次重试 |
| `Batch` 逐句 | 独立或关联 | 独立或关联 | 独立 | `auto` 自动选择。旧图在 Q4 上把显式的 `linked` 改为 `auto` 或 `independent` |
| `LongForm` 长文 | 独立或关联 | 独立或关联 | 独立 | 各段复用同一模型选项并按顺序拼接，可设置段间留白 |
| `LiveText` 实时追加 | 上一段音频 | 上一段音频 | 独立追加 | 每次追加都可复用角色参考。FP8 保留其前瞻生成 |
| `Realtime` 实时语音 | ✓ | ✓ | ✓ | 五语有中英日韩粤预设，另两款有中英预设。三者均支持有逐字稿的个人参考音 |
| `Unload` 释放模型 | ✓ | ✓ | ✓ | 接上模型端口可卸载当前对应引擎，保留网关，之后再次生成时重新加载 |
| `Benchmark` 固定基准 | ✓ | ✓ | ✓ | 报告中记录实际模型 ID 和 SHA-256。可选冷启动加立即复测 |
| `BenchmarkReport` 归档报告 | ✓ | ✓ | ✓ | 归档上游报告和对应的回读结果 |

五语及 NVFP4 的 `continue` 和 `revise` 会把上一段实际生成的 PCM 和台词交给 audio.cpp 重新编码。请连接同一模型及版本的 `history`。单次历史限 5 MiB PCM16 WAV 和 4096 字符，长稿请先分句。Q4 的 speech.cpp 接口没有跨请求的声学历史。三个 GGUF 的逐角色路径每个角色接一份参考音。需要同角色多份参考、整场联合采样或双侧上下文补录时选择 FP8。

## 其余 35 个节点用什么权重

下表中的音频和参考资产均可与三种 GGUF 搭配。表内列出了每个节点的输入来源。完整输入说明和示例见[49 个节点与工作流](功能与工作流.md)。

| 节点 | 审查结果 |
|---|---|
| `Reference`、`TrimReference` | 角色、逐字稿与标准 AUDIO。裁剪后的录音可直接传给 GGUF |
| `SaveVoice`、`FindVoice`、`AutoCast` | 保存、查询和选角使用 SQLite。画布与网关使用同一数据库即可共用音色 ID |
| `Script`、`Direct`、`Pronunciation`、`SuggestCues`、`Chunks` | 处理台本、角色、读音与分块。台本的 `text` 和 `cast` 可直接驱动 GGUF |
| `ReadSRT`、`ReadBook`、`CueSheet` | 读取字幕、书稿和台词表，可接任一后端的逐句生成 |
| `CollectTakes`、`PutTake`、`MixTimeline`、`TimelineEditor` | 收集、替换、剪辑或混音标准 AUDIO |
| `ExportProject`、`RestoreProject`、`MasterAudio`、`JoinAudio` | 读写工程、母带和拼接处理使用已生成的音频 |
| `LocalASR` | 转写参考录音。选 Whisper small 或中文 Paraformer，`model_path` 留空自动查找，或填对应的 .pt 文件 / Paraformer 目录 |
| `ForcedAlign` | 输入任一后端的 AUDIO 与逐字稿，用专用 Whisper small 对齐 |
| `TranscriptEdit`、`WordRegion`、`EditRegion` | 校订稿件或计算时间边界，波形选区可处理任一来源。下游原生补录选 FP8 |
| `ReadbackCheck` | 比对已有识别文本、原稿和音频，分析错漏与静音 |
| `SpeakerCheck`、`SpeakerTurns` | 使用 CAMPPlus 权重比较声线或按字幕段聚类 |
| `DubbingScript` | 人工译稿可直接使用。自动翻译使用 OPUS-MT 或自备 NLLB 目录 |
| `SeparateStems` | 人声分离使用 BS-RoFormer。可用 `JR_DRAMA3_GPT_SOVITS_DIR` 指向 GPT-SoVITS 根目录 |
| `VideoAudio`、`DubMix`、`ReplaceTrack` | 用原始视频和 AUDIO 提取、混音、合轨，抽取和合轨需要本地 FFmpeg |
| `H3Timing` | 把已有配音补齐到 H3 的帧数，视频模型由后续 H3 工作流加载 |

## 实测范围与复测

2026-11-24 的完整回归在 Windows 和 Ubuntu 22.04 各通过 87 项，均无跳过。五语的普通话、英语、日语、韩语和粤语预设均通过实际音频输出检查。

| 环境 | 真实权重与引擎 |
|---|---|
| Windows、RTX 5090 | audio.cpp CUDA 运行五语和 NVFP4，speech.cpp NVIDIA Vulkan 运行 Q4。三者均经生产节点生成 44.1 kHz 单声道非静音音频，涵盖参考克隆、候选取回、逐句、长文、设计、实时语音、追加、回听和基准 |
| Ubuntu 22.04、WSL2、同一块 RTX 5090 | 使用 Linux 可执行文件和 Linux Python。五语和 NVFP4 使用 CUDA。Q4 在本机可用的 Linux CPU 后端完成参考克隆、候选、逐句、长文、设计和实时语音。Linux 裸机 NVIDIA Vulkan 仍需在可枚举该设备的主机复测 |

两套系统均核对 49 个节点的注册、输入输出和仓库示例中的节点 ID，也分别向实际 ComfyUI 队列提交五语单句、参考克隆和导演返修，取回音频和模型报告。辅助模型测试覆盖实际的 Whisper、Paraformer、CAMPPlus、双向 OPUS 翻译和 BS-RoFormer。H3 完整视频生成、自备 NLLB 权重、其他显卡的显存和音质表现分别需要对应模型、硬件和听审。本轮通过音频形状、采样率、有限值、非静音及完成状态检查推理输出。

服务生命周期测试还复现了一个 Ubuntu 启动时序问题。部分引擎进程在创建瞬间向系统报告空命令行，旧启动器会写入空的 PID 匹配信息。启动器现在保存实际启动参数，卸载时核对进程身份与端口释放情况。旧记录缺少参数时，只有安装路径和引擎参数都匹配才恢复管理。

**在自己的机器复测。** 网关和 ComfyUI 更新到同一版本后同时重启。以下在插件根目录、ComfyUI 的 Python 环境运行。端口示例 8188 请换为本机实际的 ComfyUI 端口。每条命令提交一个真正的队列任务，并把音频与含模型 ID 的 JSON 报告写入对应目录。

```text
python -B tools/verify_comfy.py en --port 8188 --model drama-3-5lang --dest .runtime/verify-5lang
python -B tools/verify_comfy.py en --port 8188 --model drama-3-nvfp4 --dest .runtime/verify-nvfp4
python -B tools/verify_comfy.py en --port 8188 --model drama-3-q4 --dest .runtime/verify-q4
```

切换权重会切换该网关的常驻引擎。复测结束后，可在画布选回常用模型再生成一句。Ubuntu Q4 部署前运行 `.runtime/speechcpp/speech devices` 核对是否列出 NVIDIA Vulkan 设备。设备列表只显示 CPU 时，本项目的默认 GPU 启动命令会报告缺少 Vulkan 设备。
