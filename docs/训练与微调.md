# 场景三 · 为 Drama 3 准备训练、微调与验收

**当前仓库发布的是推理节点、量化转换器和语音服务。仓库内没有 Drama 3 训练器。** Fish Audio 的 Drama 3 发布说明也明确列出，该版本移除了训练脚本、LoRA、数据集与 VQ 提取工具。技术报告描述了模型训练方法，但不能直接作为本仓库可执行的微调流程。下面按实际能完成的步骤，说明如何选路线、整理数据、建立基线，以及接入外部训练器后如何验收。[Fish Audio 发布说明](https://github.com/fishaudio/fish-speech/releases/tag/v3.0.0-beta) · [Drama 3 技术报告](https://arxiv.org/abs/2610.18010) · [项目采用的推理源码版本](https://github.com/fishaudio/fish-speech/tree/0f8a12e8a651062fdee9c33a894bdccd3a8513f1)

## 1. 先确定要交付什么

| 目标 | 应采用的流程 | 最终保存什么 |
|---|---|---|
| 让 Hermes 用一个人的声音朗读 | 在 8195 注册一段清晰参考音和对应逐字稿，或在画布执行「保存音色版本」 | SQLite 中的录音、文字、元数据，以及供客户端使用的 `voice_id` |
| 修改模型对某些发音、风格、领域词的表现 | 在明确支持该 Drama 3 基座的外部训练器中微调或训练 LoRA | 训练配置、基座版本、checkpoint 或适配器，以及评估样音 |
| 降低现有五语模型的部署显存 | 使用本项目的五语转换与专家缓存方案 | GGUF 和同名 SHA-256 文件。[五语转换说明](五语推理.md#转换与复测) |

如果只需要第一行，现成模型即可工作。API 部署与语音注册见[Hermes 独立 API 指南](Hermes独立API部署.md)，画布见[ComfyUI 纯推理指南](ComfyUI纯推理.md)。

## 2. 在独立目录准备数据

保留原始录音，再从副本切片。每个切片保留原始录音编号与起止时间，逐字稿以该片段实际发音为准。跨语种或粤语素材记录语种和说话人。数量可先从覆盖目标读音的小批素材开始。训练时的采样率、声道、长度上限、分词和 codec 格式由所选训练器决定。

Windows 可以把素材和产物放在单独的数据盘。

```powershell
$work = 'D:\Drama3-Training'
'raw','clips','manifests','checkpoints','eval' | ForEach-Object {
    New-Item -ItemType Directory -Force (Join-Path $work $_) | Out-Null
}
```

Ubuntu 可以在用户目录下建立同样的结构。

```bash
WORK="$HOME/drama3-training"
mkdir -p "$WORK"/{raw,clips,manifests,checkpoints,eval}
```

- `raw/` 存原始录音。`clips/` 存切片。记录素材来源和允许的使用范围，尤其是他人的声音。
- `manifests/` 存清单和数据版本。下面是**项目整理数据的 JSONL 示例**，每行一条。接入训练器时再映射为它需要的字段和格式。它不会被 8195 自动读取。
- `checkpoints/` 存每次运行的配置和权重，`eval/` 存固定题单、基线与候选样音。将同一段原录音及其切片划在同一集合，按录音场次留出验证集，避免把同一声音片段同时用于学习和打分。

```jsonl
{"audio":"clips/session01-001.wav","text":"早上好，今天九点开会。","speaker":"speaker_a","language":"zh","source":"session01","split":"train"}
{"audio":"clips/session09-001.wav","text":"请把会议时间改到十点半。","speaker":"speaker_a","language":"zh","source":"session09","split":"validation"}
```

清洗时逐条检查音频能解码、声道和采样率符合所选工具、文字与音频边界对应。剔除削波、背景音乐盖过人声、多人重叠且未标角色的片段。用离线转写生成初稿后，人工核对姓名、数字、粤语用字和切片末尾。现有 `voice_id` 是一次参考音版本的索引。如需将素材用于训练，应保留或导出实际音频和文字。

## 3. 先建立可比较的推理基线

从验证集之外准备固定试听题单，分别覆盖训练中常见的说话方式和从未出现的句子，保留参考音、准确逐字稿、随机种子、模型版本、采样参数和生成文本。比如想改善人名发音，应同时记录该人名、相似音节和完全无关的对照句。

如果已有五语 8195 服务，可在**服务所在机器**的项目根目录运行项目基准工具。它通过本机服务生成普通话、英语、日语、韩语、粤语 15 条样音和测量结果。显存采样使用 `nvidia-ml-py`。请在有上述依赖的 Python 虚拟环境中运行。

```text
python -m pip install nvidia-ml-py
python -B tools/benchmark_realtime.py --model drama-3-5lang --five-languages --repeats 1 --output outputs/training-baseline
```

自己的训练集还应另备同说话人、未见台词的测试样音。可记录漏读、重复、错音、角色相似度，以及由同一组听者进行的盲听结果。推理基线占用的显存只能用于估算部署。训练还取决于可训练参数量、优化器状态、序列长度、激活和卸载策略。

## 4. 确认外部训练器兼容，再开训练作业

向训练器维护方确认**明确支持的模型仓库、revision、架构与权重精度**。本项目使用的官方教师快照是 `fishaudio/drama-3@78e5ab79e49aa9a25abe8799eff2c4d73a1c3216`，五语精简模型另有独立的源检查点。它们的推理加载路径、音频编解码和权重布局需要分别核对。[教师快照](https://huggingface.co/fishaudio/drama-3/tree/78e5ab79e49aa9a25abe8799eff2c4d73a1c3216) · [五语源检查点](https://huggingface.co/ThinkingVibeCoder/Drama-3-Tier2-5Lang-INT3/tree/e3855f74beb7579fcfbe7aadccf9ee9ab330404e)

1. **建训练环境。** 记录训练器版本、Python、PyTorch、驱动、GPU 和训练器给出的安装命令，使用独立 venv。先确认支持 Windows 原生、WSL 或 Ubuntu 中的哪一种。ComfyUI 的推理 venv 可以继续提供原版基线。
2. **跑通最小批次。** 先验证一条真实音频经过训练器的 tokenizer/codec 后能参与前向、反向和参数更新。记录可训练层、实际显存峰值和一次保存所需磁盘，再决定批量和梯度累积。12 GiB/16 GiB 的五语推理档位不能推出训练显存。
3. **验证保存与恢复。** 从短作业写出的 checkpoint 恢复，确认 step、优化器状态和学习率符合该训练方式。若产物是 LoRA，记录层名、rank、缩放、对应基座和加载方法。完成一次独立进程中的试听后再扩大数据量。
4. **比较而后部署。** 固定参考音、台词和可复用的采样设置，比较原始基座与候选产物。保留原始权重和运行记录，单独保存通过验收的候选版本。模型材料的使用条件见[许可证](../licenses/Fish-Audio-Community-License.txt)。

具体训练命令、LoRA 注入层和数据转换参数以经过验证的对应训练器为准。早期 Fish Speech 版本的同名脚本针对不同模型，直接套用可能在加载阶段失败，也可能只更新了一部分预期参数。

## 5. 训练结果怎样接入推理

优先使用训练器配套的推理入口验证新权重能否独立合成。随后若要接回这个项目，请按目标入口核对加载、注册与验收条件。

| 要接的入口 | 当前实现 | 接入新产物需要什么 |
|---|---|---|
| ComfyUI FP8 教师 | 加载并逐项校验固定快照 | 支持目标 checkpoint 或 LoRA 的加载器、配套配置、codec 与验证用例 |
| 8195 的 NVFP4 / Q4_K | 核对固定模型摘要，并使用对应原生引擎 | 与引擎兼容的转换产物、新模型登记和独立的校验信息 |
| 8195 的五语模型 | 转换器校验固定上游源，运行时核对 GGUF 的本地 SHA-256 校验文件 | 兼容的架构、词表、codec、模型元数据和经过验证的转换路径。还需要用样音验收转换结果 |

在现有服务直接把 `JR_DRAMA3_*_MODEL` 改指训练输出，只会改变查找路径。当前仓库尚未提供任意训练 checkpoint 或 LoRA 的即插即用入口。[教师加载实现](../jr_teacher.py) · [五语转换器](../tools/prepare_five_lang.py) · [实时启动器](../tools/realtime_service.py)
