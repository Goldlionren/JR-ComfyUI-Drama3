# 五语模型推理

**Built with Fish Audio**。模型 ID 为 `drama-3-5lang`。普通话、英语、日语、韩语、粤语对应的内置参考音色依次为 `zh`、`en`、`ja`、`ko`、`yue`。跨语种生成时，参考音色会影响口音，尤其是粤语。日、韩、粤语预设来自本项目在开发机生成的合成录音。

## Windows 推理机

将 Windows 推理包解压到工作盘，保持 `JR-ComfyUI-Drama3` 目录内部结构。它包含节点、五语 GGUF、校验文件、三个 GPU 架构的同一份推理引擎及 cuBLAS 13 DLL。主机需要兼容 CUDA 13 的 NVIDIA 驱动、AVX2 CPU 和 Microsoft Visual C++ 2015–2022 x64 运行库。12 GiB 档会在系统内存中固定约 8.63 GiB 的专家权重，请为 ComfyUI、驱动和服务保留额外内存。

如果 ComfyUI 的 `custom_nodes\JR-ComfyUI-Drama3` 已经链接到项目，直接使用已有链接。首次安装且尚无链接时，在 ComfyUI 根目录的 PowerShell 执行以下命令。本例项目在 `F:\AI`。

```powershell
New-Item -ItemType Junction -Path '.\custom_nodes\JR-ComfyUI-Drama3' -Target 'F:\AI\JR-ComfyUI-Drama3'
```

在 ComfyUI Desktop 的 `(.venv)` Terminal 中运行以下命令。安装或更新节点后重启 ComfyUI，并刷新画布。

```powershell
Set-Location 'F:\AI\JR-ComfyUI-Drama3'
python -m pip install -r .\tools\requirements-realtime.txt
python -B .\tools\realtime_service.py start --backend 5lang
(Invoke-RestMethod 'http://192.168.1.241:8195/health').data
```

默认显存预算为 12 GiB。16 GiB 及以上的卡可启用全模型驻留；如果启动时可用显存较少，服务会改用专家缓存。修改预算需要重新启动服务。

```powershell
python -B .\tools\realtime_service.py stop
$env:JR_DRAMA3_VRAM_GIB = '16'
python -B .\tools\realtime_service.py start --backend 5lang
```

以下请求使用示例服务器地址 `192.168.1.241`，请换成实际服务器 IP 或域名。

## 画布和 API

加载示例 07 或 08，在「Drama 3 · 实时语音」将 `model` 设为 `drama-3-5lang`。例如粤语对白选择 `voice=yue`。自定义声音仍可连接参考 AUDIO 并填写逐字稿。旧工作流的 `drama-3` 使用当前常驻模型。

如果工作流用「离线语音转写」生成参考逐字稿，在该节点选择 `Whisper small`，将 `model_path` 留空。第一次使用时，可在 ComfyUI Desktop 的 Terminal 运行以下命令准备转写权重。已安装的权重通过校验后会直接复用。

```powershell
Set-Location 'F:\AI\JR-ComfyUI-Drama3'
python -B .\jr_analysis_prepare.py whisper
```

在此目录布局下，手填 Whisper 路径为 `F:\AI\JR-ComfyUI-Drama3\.runtime\aux\whisper-small.pt`。改选 `Paraformer zh` 时填写其完整模型目录。若提示缺少 Python 模块 `whisper`，在同一 Terminal 运行 `python -m pip install openai-whisper`。

下面的请求会自动切换到五语模型，生成本地 WAV。PowerShell 使用 UTF-8 传送台词。

```powershell
$base = 'http://192.168.1.241:8195'
(Invoke-RestMethod "$base/v1/models").data | Select-Object id, installed, active
$body = @{ model='drama-3-5lang'; voice='yue'; input='落緊雨呀，記得帶把遮出街。'; response_format='wav'; seed=42 } | ConvertTo-Json -Compress
Invoke-WebRequest "$base/v1/audio/speech" -Method Post -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($body)) -OutFile '.\five-lang.wav'
```

也可先显式切换，再将多个客户端指向当前模型。支持的具体 ID 为 `drama-3-5lang`、`drama-3-q4`、`drama-3-nvfp4`。后两款分别安装对应的 GGUF 和引擎后即可切换。一次只驻留一个量化引擎，切换或朗读期间，并发请求收到 HTTP 429。所选模型缺失时，服务返回 503。

```powershell
Invoke-RestMethod "$base/v1/models/select" -Method Post -ContentType 'application/json' -Body '{"model":"drama-3-5lang"}'
(Invoke-RestMethod "$base/v1/audio/voices").data
```

## 转换与复测

推理包已经完成转换。开发机从固定版本的五语检查点构建，校验权重、词表与编解码器，按原始行号逐层保留全部 6,858 个专家。紧凑版沿用训练后的 INT3 有符号系数，为 Q3_K 拟合每组缩放系数；密集投影和主要嵌入使用 Q8，路由器使用 FP32，保留 4,097 行语义输出和原始音频编解码器。较大的数值对照包可用 `tools/prepare_five_lang.py --reference` 生成。[上游五语检查点](https://huggingface.co/ThinkingVibeCoder/Drama-3-Tier2-5Lang-INT3/tree/e3855f74beb7579fcfbe7aadccf9ee9ab330404e)

有 PyTorch 的开发环境可按以下命令从源构建。Windows 源码编译另需 CUDA 13 工具链及 Visual Studio C++ Build Tools；转换期间需要临时磁盘空间。复制已生成的 GGUF 时同时复制同名的 `.gguf.sha256`。通过 `JR_DRAMA3_5LANG_MODEL` 可指定该 GGUF 的绝对路径。

```powershell
python -m pip install 'gguf==0.19.0' safetensors huggingface_hub
.\tools\prepare_realtime.ps1 -Backend 5lang
python -B .\tools\benchmark_realtime.py --model drama-3-5lang --five-languages --repeats 1 --output .\outputs\five-lang
```

复测工具会保存每句 WAV、首包延迟、实时率和整卡显存采样峰值。它使用 Python 包 `nvidia-ml-py` 读取 NVML。评分可使用本地 SenseVoiceSmall 与 CAMPPlus 权重，通过 `--review --sensevoice 路径 --speaker-model 路径` 运行。语种识别和转写只能检验语种、漏读与部分错音，口音和自然度仍需试听。

## 5090 开发机实测

Windows，RTX 5090，驱动 610.88。下表使用同一份 13.14 GiB GGUF、同语种参考音色和相同种子，每种语言三句。整卡显存由 NVML 每 75 ms 采样。实时率为生成时间除以成品时长，统计时服务已加载。

| 配置 | 专家权重放置 | 15 句整卡峰值 | 中位实时率 | 自动语种识别 |
|---|---|---:|---:|---:|
| 12 GiB | 每层最多 100 个 GPU 缓存槽，完整专家组保存在系统内存 | 11.16 GiB | 0.48 | 15/15 |
| 16 GiB | 可用显存充足时，完整模型常驻 GPU | 14.65 GiB | 0.20 | 15/15 |

SenseVoiceSmall 自动识别后，按英文单词、其他语种字符计数。共 202 个单位，12 GiB 档有 4 处编辑差异，16 GiB 档有 7 处，保留原始专家数值的对照包有 7 处。12 GiB 档的 4 处来自日语 2 处、韩语 1 处、粤语 1 处。本次结果是小样本转写比较。独立抽查覆盖全部 40 层、320 个专家、23,592,960 个权重值，紧凑专家相对原始 INT3 权重的均方根误差为 0.574%。

真实 ComfyUI 示例 07 从 Q4 切入五语模型后输出 35 个音频块，最终预览与直播 PCM 对齐。较长的自定义参考录音与 ComfyUI 同时运行时另测得 11.52 GiB。接受的录音和逐字稿还受 2,048 token 总上下文约束；超出时应选用更短的录音片段和对应逐字稿。

Windows 二进制已用 `cuobjdump` 检查，包含 SM 86、89、120a 的 CUDA 代码。RTX 3060、4060 Ti、4080 SUPER、5060 Ti 的实卡吞吐和显存仍待对应机器复测。[NVIDIA GPU 计算能力表](https://developer.nvidia.com/cuda/gpus)
