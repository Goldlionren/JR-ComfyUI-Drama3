# 功能与工作流

下表列出本插件注册的 **49 个 ComfyUI 节点**。在画布按中文名称或节点 ID 搜索即可。表内省略 ID 的共同前缀 `JRDrama3`，例如 `Teacher` 的完整 ID 是 `JRDrama3Teacher`。API 入口在页末。历史验收另按 33 个需求编号记录，包含已验证、需人工听审和未交付的范围。[验收明细](功能验收.md)

## 教师、实时与局部编辑（13）

| 节点 | 用途 |
|---|---|
| `Teacher` 本地 FP8 教师 | 定位并验证官方教师，选择默认注意力或可选 FLA 后端。输出接生成、候选或补录节点。 |
| `Sampling` 采样设置 | 设置温度、top-p、top-k 和生成帧上限，同一份设置可供多个节点使用。 |
| `Generate` 本地语音生成 | 生成单句、按描述设计人声或渲染多角色场景；可凭历史续写、导演返修，输出 AUDIO、历史和报告。 |
| `Candidates` 生成候选版本 | 为同一句生成多版，记录各自的种子与参数，供试听与选择。 |
| `SelectTake` 选择或锁定候选 | 按候选序号取音频和历史，或用已保存的 take ID 取回一样的录音。 |
| `Batch` 逐句生成与断点续作 | 从台词表逐句生成并持久化，中断后重新排队可续作；关联模式会重算依赖前文的后续句。 |
| `LongForm` 连续长文 | 分段承接前文表演，输出整轨、片段和报告。 |
| `CheckedTake` 回听校验与限次重录 | 用 Whisper 回读与原稿比较，按设定重试上限生成，并保留尝试报告。 |
| `EditRegion` 波形与补录选区 | 鼠标拖选或按秒、采样、codec 帧、视频帧定位；前后两段音频也可组成插词接缝。 |
| `Infill` 上下文局部补录 | 用原音双侧上下文和完整新稿补录。44.1 kHz 单声道输入在选区外逐样本保留，补录段可以改变长度。 |
| `LiveText` 实时追加台词 | 排队后逐段向教师送入新台词，完成或到达空闲时限后合成末段。 |
| `Realtime` 中英实时语音 | 连接本机量化 API，使用预设或参考音，支持混读、语气提示、流式试听及完整 AUDIO。 |
| `Unload` 释放教师 | 释放教师和相关缓存，可连接前一道 AUDIO 来确定释放顺序。 |

## 台本与选角（10）

| 节点 | 用途 |
|---|---|
| `Reference` 角色与声音参考 | 按编号 0–15 和名称绑定参考音、逐字稿及小传；链式加入更多角色或同一角色的多个参考。 |
| `TrimReference` 参考音裁剪 | 指定录音起止秒数，可去除边缘静音或归一化峰值。 |
| `SaveVoice` 保存音色版本 | 将参考录音、逐字稿和标签一起保存，返回持久版本 ID。 |
| `FindVoice` 检索与载入音色 | 按名称、语言、描述、标签或完整版本 ID 查找，并取回录音和逐字稿。 |
| `AutoCast` 按描述选角 | 在本机声库匹配角色，保留已手工绑定的声音，允许逐角色指定版本 ID。 |
| `Script` 多角色台本与场景 | 将逐行角色对话、场景描述和人物小传转换成角色表、台词文本与场景 JSON。 |
| `Direct` 导演与标记校验 | 检查角色编号、标签开闭和范围，可加入逐轮导演提示并预览差异。 |
| `Pronunciation` 中英发音词典 | 替代读法、中文拼音、英文 ARPAbet、数字及日期朗读，并保留原文；局部语言切换属实验功能。 |
| `SuggestCues` 导演标记建议 | 按文本规则给出停顿、语气等建议，预览后可接受或手工修改。 |
| `Chunks` 长文分块 | 按 UTF-8 字节、句段和标记边界拆稿，保留角色与跨块范围标签。 |

## 字幕、工程与交付（11）

| 节点 | 用途 |
|---|---|
| `ReadSRT` 导入字幕 | 读取 SRT 文本或本地字幕文件，保留时间码并生成台词表。 |
| `ReadBook` 导入书稿 | 从本机 TXT/EPUB 提取章节，进入有声书配音流程。 |
| `CueSheet` 编辑台词表 | 维护台词 ID、文字、角色与时间信息，输出后续生成使用的台词表。 |
| `CollectTakes` 收集逐句音频 | 将逐句 AUDIO 与对应台词合成一条时间线。 |
| `PutTake` 加入或替换录音 | 按台词位置添加或替换一条录音，保留工程里的其他条目。 |
| `TimelineEditor` 分轨台本编辑与试听 | 在画布上试听、锁定、裁切、调整时间和角色，修改字幕后再次运行。 |
| `MixTimeline` 混音或单角色分轨 | 处理间隔、重叠与超时，可按上限变速适配或只输出选择的角色。 |
| `MasterAudio` 音频母带 | 对成品裁切、淡入淡出和增益处理，按节点选项整理交付响度。 |
| `JoinAudio` 拼接音频 | 用间隔或交叉淡化衔接两段音频。 |
| `ExportProject` 导出工程及分轨 | 输出总轨、字幕、清单、可恢复工程包，可选逐句及角色轨、FLAC/MP3 或分章 M4B。接入另一语言时间线可导出双语版本。 |
| `RestoreProject` 恢复工程 | 从本机 input/output 中的工程包取回台词、源录音、角色和可用的工作流数据。 |

## 转写、质检与视频（13）

| 节点 | 用途 |
|---|---|
| `LocalASR` 离线语音转写 | 使用 Whisper small 转写中文、英文和混读，中文另可选本地 Paraformer。 |
| `TranscriptEdit` 参考逐字稿 | 直接填写实际台词或校订 ASR 结果，再接声音参考。 |
| `ForcedAlign` 按稿强制对齐 | 用 Whisper 交叉注意力估算词边界。超过 30 秒的材料需要带起止时间的分段稿。 |
| `WordRegion` 按词选择修补区域 | 将词序号转换成补录起止秒数，允许手工调整边界。 |
| `ReadbackCheck` 读稿质检 | 比对原稿、回读文字与音频，报告错漏、静音、截断和重试提示。 |
| `SpeakerCheck` 声线相似度复核 | 比较参考音和生成音的 CAMPPlus 声纹余弦值，标出需要试听的片段。 |
| `SpeakerTurns` 为字幕段分配说话人 | 按每段的声纹聚类；重叠对白需拆段或人工校订。 |
| `DubbingScript` 原轴译配稿 | 保留角色及时间轴，接受逐行人工译稿、离线 OPUS-MT 或自备 NLLB。 |
| `VideoAudio` 视频抽取原声 | 用 FFmpeg 提取视频第一条音轨。 |
| `SeparateStems` 分离对白与背景 | 用本地 BS-RoFormer 得到人声与背景两轨。 |
| `DubMix` 对白与背景混音 | 按时间偏移合入配音，分别调节对白和背景增益。 |
| `ReplaceTrack` 按原画面合轨 | 保留有效视频压缩流，按画面时长对齐新音轨，输出 MKV。 |
| `H3Timing` 将最终台词接入口型工作流 | 将配音补齐到 H3 的 24 fps、17k+5 帧网格，交给外部 H3 节点生成视频。 |

## 性能与听审（2）

| 节点 | 用途 |
|---|---|
| `Benchmark` 中英固定基准 | 用仓库的两份合成参考、固定台本及种子测中文、英文、混读，支持冷/热对照。 |
| `BenchmarkReport` 归档基准报告 | 将耗时、内存、回读差错和听审意见写入有效输出目录下的 `JR-Drama3/benchmarks`。 |

## HTTP 接口

| 服务 | 接口与能力 |
|---|---|
| 8193 教师 | `GET /health`、`GET /v1/models`、`GET /v1/audio/voices`、`POST /v1/audio/speech`。支持设计音色或本机声库 ID、导演说明、速度、种子和六种音频格式。 |
| 8195 实时 | 同样提供健康、模型、音色列表和语音合成。支持 WAV、PCM 和 PCM 的 SSE 事件。NVFP4 另支持临时参考、已保存的 ID、`POST /v1/audio/voices` 注册。Q4_K 使用内置预设。 |

独立浏览器制作工作台和通用远程 GPU 教师适配属于历史需求中的未交付项。助手对话、麦克风识别、电话和 VAD 由宿主提供。[实时 API 用法](中英实时语音.md) · [模型与外部依赖](模型.md) · [找到生成的文件](声音资产.md)
