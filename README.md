# JR Drama 3 for ComfyUI

**Built with Fish Audio**。在本地 NVIDIA GPU 上制作普通话、英语及中英混读配音。可以在 ComfyUI 里导台词、挑选录音、补录和导出工程，也可以让 Hermes 等客户端通过 HTTP 获取语音。

**先按目标选路线。** 用现成模型配音、克隆声音或接 Hermes，请看[只做推理](#只做推理)。要用数据更新模型权重或训练 LoRA，请看[需要训练](#需要训练)。

## 只做推理

Windows 和 Ubuntu 都按下表选择入口。四种方式都使用现成权重。FP8 教师、NVFP4 和 Q4_K 均可用参考录音和逐字稿克隆音色。只用实时服务的内置中英文音色时，可以跳过参考录音和逐字稿。

| 你想做什么 | 要运行的组件 | 要下载的主模型 |
|---|---|---|
| 在 ComfyUI 制作配音、编辑多角色对白和有声书 | ComfyUI + 本插件，在画布加载本地教师 | 官方 FP8 十五分片，约 41.50 GB |
| 给 Hermes 或程序提供低延迟语音，不开画布 | 独立实时服务，客户端连接 `8195/v1`，内部引擎走 `127.0.0.1:8196` | NVFP4（约 22.24 GB）或 Q4_K（约 20.79 GB），二选一 |
| 在 ComfyUI 使用量化实时语音 | 本插件 + **同机** 8195 服务，打开示例 07 或 08 | 与独立实时服务共用一份 GGUF |
| 通过 API 使用完整 FP8 教师 | 本机 8193 网关 + 装有本插件的 ComfyUI 队列。优先 8188，备用 8194 | 与教师节点共用一份 FP8 权重 |

只用实时 API 时可跳过 ComfyUI 安装和 FP8 下载。**已有本项目的 NVFP4 GGUF**，可直接在 GPU 服务器上复用该文件。两个系统的模型路径、引擎编译、启动命令和后端检查见 [NVFP4 加速指南](docs/NVFP4加速.md)。

已配置局域网监听的 8195 可以服务其他机器上的客户端。实时节点本身连接回环地址。8193 等完整文本合成完毕后返回文件，8195 可以边生成边播放。

### 安装和使用

1. 按操作系统和用途安装，在教程末尾生成第一段 WAV。[Windows 与 Ubuntu 安装部署](docs/安装部署.md)
2. 按所用节点下载模型，确认文件名、磁盘空间、查找顺序以及离线安装方式。[模型下载与存放](docs/模型.md)
3. 找到自己的参考录音、音色数据库、候选、工程和成品，或把它们搬到新机器。[声音资产与备份](docs/声音资产.md)
4. 按任务选择工作流，或查找每个节点的作用。[功能与工作流](docs/功能与工作流.md) · [33 项范围与历史验收](docs/功能验收.md)

试听仓库里的三段 FP8 教师样音：[中文](docs/samples/zh.flac) · [英文](docs/samples/en.flac) · [中英混读](docs/samples/mixed.flac)。

### 第一次在画布生成

将 [01 中英单句](example_workflows/01-中英单句.json) 拖到画布。「本地 FP8 教师」保留空目录即可自动定位已准备好的权重。在「本地语音生成」输入一句台词，运行队列，从预览节点试听。要留下可以独立播放的文件，请把 `AUDIO` 也接到 ComfyUI 原生 Save Audio。示例 04/05 需要你选择自己的输入音频。

角色克隆需要参考音与录音中**实际说出的逐字稿**。将两者接入「角色与声音参考」，再把角色接到生成节点。需要长期复用时，执行「保存音色版本」并保留输出的 `voice_id`。多角色整场生成使用 `scene`，返修使用上一版 `history` 和 `revise`。FLA 加速默认关闭，可以在准备好可选内核后切换。

## 需要训练

**当前仓库只提供推理和配音制作。** 如果目标是微调 Drama 3、训练声音 LoRA 或蒸馏新模型，需要另选明确支持 Drama 3 的训练工具。安装指南列出了 Windows 和 Ubuntu 的数据集与训练输出目录示例，也说明了自定义权重的加载限制。[训练前的准备与权重兼容性](docs/安装部署.md#需要训练)
